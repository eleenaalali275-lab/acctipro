ACCTIPRO WEB APP — HOW TO PUBLISH FREE

Files:
- index.html: the app
- manifest.webmanifest: install metadata
- sw.js: offline cache support
- icon.svg: app icon

Recommended beginner route: GitHub Pages
1. On a computer (easiest) or phone browser, create/sign into a GitHub account.
2. Create a NEW public repository named acctipro (do not upload personal information).
3. Upload all four files from this folder into the repository root. Ensure index.html is at the top level, not inside another folder.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; branch main and folder /(root); Save.
6. Wait a few minutes. GitHub will show a URL similar to https://YOUR-USERNAME.github.io/acctipro/ . Use the exact URL shown by GitHub.
7. Open that HTTPS URL in Chrome on the Redmi 15C.
8. Tap Chrome's ⋮ menu. Choose Install app if shown; otherwise choose Add to Home screen → Install/Add.
9. Launch AcctiPro from the new home-screen icon.

Notes:
- Do not type a guessed URL; use the URL GitHub displays.
- A public repository means the app source is public. This app contains only fictional practice data and should not contain private details.
- The app is a learning prototype, not professional accounting software. Practice records are currently held in the page's memory and may reset when reloaded. Do not rely on it to store records permanently.
- GitHub Pages is free for public repositories. GitHub's interface may change.
